# 艺术风格预设

预设是可调整的视觉参数，不是必须一成不变的模板。每次只改变用户反馈指向的参数。

## light-ink-color-wash

适合古建筑、现代建筑、山水、街景、静物和具有东方气质的照片。

- 媒介：淡水墨、轻彩、宣纸或手工纸；
- 线条：可见但不压黑，建筑结构用较清楚的墨线，背景用更松的洗染；
- 色彩：低至中等饱和度，浅蓝、蓝灰、灰褐、淡玉绿为主；
- 光线：清淡、通透、安静的日间光线；
- 构图：优先跟随源图比例和主体位置；
- 主体：主体结构清晰，次要背景允许合并和简化；
- 建筑：保留建筑的时代类型和关键轮廓；现代曲面、幕墙和壳体不被传统建筑元素替换；
- 清洁：去除源图水印、小字、角标、logo、签名和伪文字；
- 避免：厚重黑块、鲜艳数码色、照片质感、3D、动漫化、额外建筑、人物、题字和印章。

### 可调参数

| 用户反馈 | 调整 | 不变 |
|---|---|---|
| 墨色太重 | 降低黑色覆盖、线条密度和局部对比度 | 主体轮廓、画幅、色板 |
| 太像照片 | 增加纸张留白、洗染和可见笔触 | 主体结构和视角 |
| 太淡、看不清 | 只增强主体轮廓和关键结构线 | 背景留白和淡彩范围 |
| 颜色太艳 | 降低饱和度、减少颜色种类 | 墨线和构图 |
| 建筑不像 | 锁定屋檐、层级、斗拱/结构件、主轮廓 | 水墨淡彩媒介 |
| 背景太乱 | 合并小树叶、云朵和杂物，增加呼吸空间 | 主体与主要视角 |
| 建筑类型跑偏 | 明确锁定古建/现代建筑身份，并强化关键结构线 | 水墨淡彩媒介和整体画幅 |

## 后续预设的最小格式

新增预设时至少写清：

1. 媒介和表面质感；
2. 线条/笔触密度；
3. 色彩与饱和度；
4. 主体保真默认值；
5. 默认画幅策略；
6. 至少三条避免项。
