# 水墨画册式上下对比版式规则

默认使用单列纵向版式：原图在上，修改图在下。两张图各自完整显示，统一宽度但不强行统一高度。对比画布本身采用水墨画册式视觉语言，让“查看差异”与“作品展示”同时成立。

## 默认参数

- 默认不使用文字、标题或解释性标签；
- 如用户明确要求题签，使用深灰墨色的小字和很短的淡墨下划线；
- 画布背景：暖米色宣纸，约 `#F1EBDD`，带极轻的纸张颗粒；
- 边缘装饰：低对比度灰青色/灰褐色水墨晕染，只出现在外边距和分隔区；
- 分隔留白：64–96 px，中央可有柔和横向笔触；
- 图片容器：不使用画框、边框或卡片；两张图直接融入宣纸背景；
- 图片边缘：采用不规则水墨淡化和湿画法晕染，边缘逐渐消失到纸张里，中心主体保持清晰；
- 视觉目标：像一件完整的水墨画册作品，不像功能说明图或普通拼图；
- 外边距：52 px；
- 输出格式：PNG；
- 默认最大宽度：1600 px。

如果用户明确要求文字，只添加用户指定的文字；否则保持无文字。用户要用于社交媒体时，可另行指定画幅，但不要默认裁切原图。
