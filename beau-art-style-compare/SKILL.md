# 原图与修改图上下对比

这个技能负责把“生成结果”变成用户容易判断、同时具有审美完整性的前后对比。它不改变图片内容，只统一尺寸、排列顺序和展示方式：原图永远在上，修改图永远在下；展示画布默认采用与 Beau 水墨作品一致的宣纸、留白和淡墨视觉语言。

## 何时触发

在以下请求中使用：

- “把原图和修改图上下放一起”；
- “让我同时看原图和结果图”；
- “生成后做 before/after 对比”；
- “上面原图，下面艺术化结果”；
- 用户已经有两张图，要求合并查看；
- 用户要求生成/编辑图片并同时展示修改前后。

如果用户只是要单独生成图片、没有要求前后对比，使用对应的生成技能即可，不必额外合成长图。

## 输入路由

1. **已有两张图**：将第一张明确标记为原图，第二张明确标记为修改图；不要凭文件名猜测，必要时查看图片内容。
2. **只有原图和修改要求**：先使用内置 `image_gen` 生成修改图。若目标是艺术画风，沿用 `beau-art-style-transfer` 的主体保真和风格规则。
3. **已有生成结果但没有显示**：先检查工具返回的图像字段或保存路径，不要盲目重新生成；找到结果后再做对比。
4. **多张候选结果**：一次只合并用户指定的一张原图和一张修改图；若用户要比较多个候选，分别生成多张对比图，不把无关候选混在一张里。

## 默认输出

每次完成后同时提供：

1. 一张纵向对比长图：原图在上，修改图在下；
2. 默认不添加任何文字；只有用户明确要求时，才添加题签或标题；
3. 原图与修改图的独立文件路径（如果它们是本轮生成或保存的文件）；
4. 一句说明本轮修改了什么。

在聊天中优先展示合成后的纵向对比长图；如果界面支持直接展开图片，也可再按顺序展示原图和修改图。使用绝对路径的 Markdown 图片链接，确保图片可以直接查看。

## 视觉与版式规则

- 原图必须在上，修改图必须在下；不能反过来；
- 两张图统一到相同显示宽度，保持各自原始宽高比；
- 不裁切主体、不拉伸变形、不旋转、不镜像；
- 两张图之间使用宣纸留白和淡墨晕染分隔；
- 不添加任何外框、画框、圆角卡片或现代 UI 容器；
- 不添加“原图”“修改后”等解释性文字，除非用户明确要求；
- 两张图的四周边缘向宣纸背景自然淡出，使用不规则水墨晕染、干湿变化和轻微飞白；主体中心保持清晰，边缘不做硬切；
- 合成背景使用暖米色宣纸纹理，边缘可有低对比度的水墨晕染，但不能抢主体；
- 整体应像一页水墨画册或展签，而不是普通图片拼接；
- 如果两张图比例不同，允许它们高度不同，但仍保持完整画面；
- 不修改图片本身的颜色、主体、文字或细节；合成只是展示层操作。

## 合成步骤

先用 `view_image` 检查原图和修改图，确认两者都真实存在并且角色没有弄反。然后使用随技能提供的脚本：

```bash
python3 <skill-path>/scripts/stack_compare.py \
  --top <absolute-path-to-original> \
  --bottom <absolute-path-to-modified> \
  --out <absolute-output-path>
```

默认行为：

- 顶部原图、底部修改图；
- 自动按统一宽度缩放，保持比例；
- 默认不添加文字，保持作品式呈现；如用户明确要求，可通过 `--top-label` 和 `--bottom-label` 添加题签；
- 默认使用 `ink-wash` 展示主题：宣纸底色、淡墨晕染、自然留白和无硬边的图片边缘；
- 默认输出 PNG；
- 不覆盖已有文件，使用新的版本化文件名。

生成后再次查看合成结果，检查顺序、完整性、标签、分隔和是否出现拉伸/裁切。合成脚本成功不等于视觉检查通过。

## 有问题时的处理

- 原图或修改图缺失：说明缺哪一张，不生成伪对比图；
- 修改图生成失败：报告生成失败，不把原图重复放两次；
- 图片尺寸差异大：通过统一宽度和保持比例处理，不裁切主体；
- 合成图显示失败：先检查输出路径和文件是否存在，再尝试重新展示；不要重复生成修改图；
- 用户要求并排或其他布局：可以调整布局，但只有明确要求时才改变默认的上下顺序；
- 用户要求其他展示风格时，才切换为简洁、现代或其他主题，不要让主题风格覆盖用户指定的艺术画风。

## 报告格式

```text
对比状态：已生成 / 已展示 / 需要人工复核 / 失败
原图：<路径或图片>
修改后：<路径或图片>
上下对比图：<路径或图片>
本轮变化：<一句话>
```

## 边界

- 不把合成图误称为新的艺术生成结果；它只是展示层产物；
- 不声称修改图质量通过，除非已实际查看修改图和合成图；
- 不覆盖原图或修改图；
- 不在对比图中添加水印、logo、签名或额外宣传文字。
